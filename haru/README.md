# 하루 (Haru) agent avatars

Profile images of 하루 agents (640×640 PNG), served by GitHub Pages so that NAVER WORKS bots and
other places can show them on any network:

    https://nakosung.github.io/haru/avatars/<id>.png

The ids are the avatar ids of the agents (`cloud`, `star`, `moon`, …), the same as in
`apps/muse/agents.py` of Strata.
