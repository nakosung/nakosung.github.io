# nakosung.github.io

Personal research site for Nako Sung / 성낙호.

## Structure

- `/` — profile, current research interests, featured notes
- `/research/` — research-note archive
- `/research/<slug>/` — standalone research notes and interactive experiments

## Publishing a new research note

1. Add a self-contained page at `research/<slug>/index.html`.
2. Keep Korean and English together when useful; prefer browser-locale detection plus a manual language switch.
3. Add the note to `research/index.html` and the featured section on `index.html` when appropriate.
4. Research notes should separate:
   - established prior work,
   - the proposed idea,
   - assumptions and scope,
   - digital-twin or experimental evidence,
   - failure conditions and fair baselines.
5. Avoid presenting exploratory simulation as measured hardware results.
