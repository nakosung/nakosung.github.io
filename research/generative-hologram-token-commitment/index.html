generative holograms and token commitment

Don’t kill Schrödinger’s cat at every token.

If an LLM or world model is a generative hologram, then a token is not the whole thought. It is a measurement. The question is whether the model should be forced to measure at every step.

Claim

Token generation should be a readout action, not necessarily the clock of thought.

Autoregressive decoding collapses a rich continuous state into one vocabulary item at every step. This is an elegant way to speak, but it may be a poor default for thinking under semantic uncertainty.

h_t → logits → softmax → token → embedding → h_{t+1}

The minimal proposal is to add one policy action: <CONT>. When selected, the model emits no token. It projects the current hidden state into the next input embedding and continues in latent space. Language becomes one mode of computation rather than the compulsory substrate of all computation.

Short versionDo not force the model to say a word before it has decided what kind of uncertainty it is carrying.
View

LLMs and world models as generative holograms

A model state is not a single sentence waiting to be printed. It is closer to a compressed interference pattern: local activations imply many possible continuations, scenes, actions, and explanations at once.

Generation is a measurement process. A next-token sample, an image patch, an action, or a predicted observation is a readout from a richer field. The readout is necessary when the system must communicate or act. It is not obvious that internal inference should be forced to collapse into the same narrow channel at the same rate.

Language model

Maintains possible semantic continuations, then commits one token.

World model

Maintains possible latent futures, then commits a prediction or action.

Premature commitment

Autoregression kills the cat every token.

The Schrödinger’s cat metaphor is only a warning about measurement. A hidden state can carry incompatible but useful hypotheses. A sampled token turns that mixture into a single public trace.

That trace helps: it gives a stable scratchpad and makes reasoning inspectable. But it also creates path dependence. Once the wrong intermediate token is written, later computation has to explain, repair, or route around that commitment.

Diffusion-style decoding points to the opposite bias. Instead of committing left-to-right immediately, it can iteratively refine a partially specified whole. Here diffusion is less a specific architecture than a principle: delay irreversible commitment while uncertainty is still globally coupled.

Adaptive compute

Depth vs. width should be chosen by uncertainty.

When uncertainty is local and mostly syntactic, more serial depth may be enough. When uncertainty is semantic, causal, or plan-level, the model may need width: maintain several hypotheses, compare them, and only then collapse.

AxisWhen usefulFailure mode
DepthContinue refining one latent trajectory.Can deepen a mistaken commitment.
WidthKeep alternative hypotheses alive.Can waste compute on shallow duplicates.
ReadoutEmit language, action, or observation prediction.Can collapse before the right uncertainty is resolved.

A controller could use entropy, semantic clustering instability, verifier confidence, value uncertainty, reward-model margin, or disagreement between probes. The important part is letting compute allocate across depth, width, and readout.

Continuous CoT

A minimal <CONT> action

Coconut showed an important version of this idea: use the last hidden state directly as the next input embedding, letting reasoning proceed in continuous space instead of always decoding a word token. This note keeps that intuition but changes the control problem.

Instead of mainly predefining a continuous-thought span with markers and curriculum training, add <CONT> to the action space during reinforcement learning. The model learns when to speak and when to keep thinking.

A = V ∪ { <CONT> }
if token ∈ V: emit token
if token = <CONT>: h_t → P(h_t) → next embedding

The softmax head does not disappear. It becomes an optional readout for probing, supervision, safety checks, or final answers. Vocabulary collapse is no longer the only way to advance a reasoning step.

Extension

Branch, merge, and recombine latent hypotheses

The one-action version is the minimal experiment. The natural extension is to branch the latent state into several hypotheses, run a small amount of depth on each, and merge or recombine before readout.

This is where the generative-hologram picture becomes operational. The model should not only maintain a blurry average of futures. It should sometimes preserve distinguishable hypotheses long enough for evidence, value, or consistency checks to act on them.

Scope

What would make this real?

This is a hypothesis, not an empirical claim. A fair test would compare standard CoT, diffusion or iterative decoding, Coconut-style continuous thought, and RL-trained <CONT> policies under equal compute budgets.

The interesting metrics are not only final accuracy. We should measure calibration after latent steps, recovery from early wrong hypotheses, semantic diversity, verifier margin before and after readout, and whether continuous states become useful or merely hide shortcuts.

핵심 주장

토큰 생성은 사고의 시계가 아니라, 필요할 때 하는 readout action이어야 한다.

Autoregressive decoding은 매 step마다 풍부한 continuous state를 vocabulary의 한 항목으로 collapse시킨다. 말하기에는 우아하지만, semantic uncertainty를 품고 생각해야 하는 기본 방식으로는 너무 이른 결정을 강요할 수 있다.

h_t → logits → softmax → token → embedding → h_{t+1}

가장 작은 제안은 policy에 <CONT> action 하나를 추가하는 것이다. 이 action이 선택되면 모델은 토큰을 내보내지 않고, 현재 hidden state를 다음 input embedding으로 projection해 latent space에서 계속 생각한다.

관점

LLM과 world model을 generative hologram으로 보기

모델의 state는 출력 대기 중인 한 문장이 아니다. 하나의 activation field 안에 여러 continuation, 장면, 행동, 설명 가능성이 동시에 들어 있는 압축된 간섭무늬에 가깝다.

이 관점에서 generation은 measurement다. next token, image patch, action, predicted observation은 더 풍부한 field에서 읽어낸 결과다. 외부와 소통하거나 행동해야 할 때 readout은 필요하지만, 내부 추론까지 같은 좁은 channel로 collapse되어야 하는지는 분명하지 않다.

Premature commitment

Autoregression은 매 token마다 슈뢰딩거의 고양이를 죽인다.

Schrödinger’s cat 비유는 measurement에 대한 경고다. hidden state는 서로 양립하기 어려운 가설들도 아직 유용한 형태로 함께 품을 수 있다. sampled token은 그 혼합 상태를 하나의 공개 trace로 바꾼다.

Diffusion-style decoding은 반대 방향의 편향을 보여준다. 바로 왼쪽에서 오른쪽으로 결정하기보다, 부분적으로 정해진 전체 object를 반복적으로 refine한다. 즉 global하게 얽혀 있는 불확실성의 irreversible commitment를 늦춘다.

Adaptive compute

Depth와 width는 uncertainty가 고르게 해야 한다.

불확실성이 local하고 syntax에 가깝다면 serial depth를 더 쓰는 것으로 충분할 수 있다. 반대로 semantic, causal, plan-level uncertainty라면 width가 필요하다. 여러 가설을 유지하고 비교한 뒤 collapse해야 한다.

controller는 entropy, semantic clustering instability, verifier confidence, value uncertainty, reward-model margin, probe disagreement 같은 신호를 쓸 수 있다. 중요한 것은 compute를 depth, width, readout 사이에 배분하게 하는 것이다.

Continuous CoT

가장 작은 <CONT> action

Coconut은 마지막 hidden state를 다음 input embedding으로 직접 사용해 reasoning이 continuous space에서 진행될 수 있음을 보여줬다. 이 노트는 그 직관을 유지하되 control problem을 바꾼다.

continuous-thought 구간을 marker와 curriculum으로 주로 정해주는 대신, reinforcement learning 단계에서 action space에 <CONT>를 추가한다. 모델은 언제 말하고 언제 계속 생각할지를 배운다.

A = V ∪ { <CONT> }
if token ∈ V: emit token
if token = <CONT>: h_t → P(h_t) → next embedding
다음 확장

Branch, merge, recombination of latent hypotheses

action 하나짜리 버전은 최소 실험이다. 자연스러운 다음 단계는 latent state를 여러 hypothesis로 branch하고, 각 hypothesis에 약간의 depth를 쓴 뒤, readout 전에 merge하거나 recombine하는 것이다.

범위

무엇을 검증해야 하나?

이 글은 hypothesis이지 empirical claim이 아니다. 같은 compute budget에서 standard CoT, diffusion/iterative decoding, Coconut-style continuous thought, RL-trained <CONT> policy를 비교해야 한다.

final accuracy만이 아니라 latent step 이후 calibration, 초기의 틀린 hypothesis로부터 회복하는 능력, alternative들의 semantic diversity, verifier margin 전후, continuous state가 shortcut을 숨기는지까지 봐야 한다.
