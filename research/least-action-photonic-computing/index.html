Can causality compute the minimum?

Encode local action as physical delay. Let propagation accumulate it. At every state, keep only the first wavefront to arrive. This note asks when such a machine is mathematically valid — and whether it could become physically useful.

A[P] = Σₖ a(xₖ→xₖ₊₁)
τₖ = τ₀ + αaₖ
earliest arrival = argminₚ A[P]

The idea is not “light is fast.”

The interesting part is that arrival order itself can become an arithmetic primitive. Propagation performs addition; causality performs the minimum; a latch remembers the winner.

Action → timeA local cost becomes a programmable true-time delay.
First arrival → minimumThe earliest signal at a complete state dominates every later history.
Winner memory → pathRecord the predecessor port and recover the final trajectory by backtracking.
Scope matters. This first architecture solves a global minimum over a discretized additive objective with a Markov-complete state. It is not yet a generic stationary-action solver.

Why can we prune early?

If two histories reach the same complete state and A arrives first, any future continuation adds the same future cost to both. The late history can never recover.

Tᴬ(j) < Tᴮ(j)
Tᴬ(j)+F(j) < Tᴮ(j)+F(j)
Exponential histories can collapse into a polynomial frontier — but only when Bellman’s principle is valid for the chosen state.

The exponential number is real — and easy to misuse.

With b states per layer and d layers, there are b^d complete histories. First-arrival pruning means only one winner per state needs to survive. But the same optimal-substructure also lets a classical dynamic program avoid exhaustive enumeration.

b^dimplicit complete histories
O(d·b²)programmable edges / classical min-plus work
O(d)physical critical propagation depth, ideally
So what would count as an advantage? Not beating brute force. The real benchmark is end-to-end time-to-solution and energy-to-solution against an optimized electronic min-plus implementation at equal accuracy and equivalent I/O accounting.

What has to be built next

1. Fiber proofProgram action with fiber delay and verify the action-to-arrival mapping and noise model.
2. First-arrival cellForward one winner, suppress late pulses, preserve cumulative time, and record the winning input.
3. Integrated fabricCombine programmable true-time-delay edges and first-arrival cells, then look for a real electronic crossover.

Relevant boundaries include Fermat–Bellman–eikonal connections, NIST temporal/race computing, photonic subset-sum machines, and programmable photonic wave propagation.
