토큰 시간 너머.

언어는 인터페이스다. 문제는 같은 직렬 token stream이 지능의 계산, 기억, 반응 방식까지 결정해야 하느냐는 것이다.

Persistent internal state를 유지하고, event가 바꾼 부분만 갱신하며, 상호작용이 필요할 때만 modality로 serialize한다.

01 / 먼저 병목부터

토큰 하나가 계산의 한 스텝이 된다.

Autoregressive LLM은 내부에 연속적인 hidden state를 가지고 있다가, 그 상태를 token 확률분포로 바꾸고 하나를 선택해 context에 붙인 뒤 다시 계산합니다.

continuous hidden state -> token -> next hidden state

여기서 hidden state는 모델이 현재 가지고 있는 연속적인 내부 표현을 뜻합니다. token은 언어 인터페이스로 드러나는 discrete symbol입니다. 이 구조에서는 아주 단순한 clock이 생깁니다. token 하나를 내보낼 때마다 visible sequence가 한 칸 앞으로 갑니다.

글을 생성할 때는 자연스러운 clock입니다. 하지만 내부 계산까지 반드시 이 clock에 맞춰야 하는지는 별개의 문제입니다.

첫 번째 완화: 매번 token을 내보내지 않아도 된다

Coconut은 중요한 가능성을 실제로 보여줍니다. reasoning의 일부 step을 먼저 언어로 decode하지 않고, 모델 내부의 연속적인 표현 상태로 그대로 다음 계산에 넘길 수 있습니다.

Latent continuation이 글에서 latent는 아직 text, speech, pixel 같은 외부 modality로 serialize되지 않은 내부의 연속 표현을 뜻합니다.

이렇게 하면 하나의 제약은 사라집니다. 내부 계산이 매 step마다 말을 할 필요는 없습니다. 하지만 질문이 하나 더 남습니다. 내부 계산 자체도 꼭 하나의 직렬 chain이어야 할까요?

02 / 하나의 chain에서 여러 변화 요소로

세계에는 한 순간에도 여러 일이 함께 존재한다.

Full-duplex assistant를 생각해 보면 쉽습니다. 답을 말하는 동안에도 새 음성이 들어오고, 상대의 의도가 바뀔 수 있고, response plan이 수정될 수 있고, 카메라 속 물체는 계속 움직입니다.

Video model은 더 직관적인 예입니다. 한 frame 안에 여러 사람, 움직이는 자동차, 조명의 변화, camera motion, 가려진 물체가 동시에 있을 수 있습니다. Video output은 한 줄의 시간축으로 serialize되지만, 그 안의 세계가 하나의 process인 것은 아닙니다.

이 요소들은 같은 순간에 바뀔 필요도 없습니다. Speaker state는 새 발화가 들어올 때 바뀌고, object state는 motion이 관측될 때 바뀌며, plan은 새로운 evidence가 의미 있을 때만 갱신될 수 있습니다.

여기서 말하는 streamStream은 내부 state 중에서 독립적인 속도로 변화할 수 있는 하나의 구성요소를 뜻합니다. Multiple streams는 여러 모델이나 여러 textual chain을 뜻하지 않습니다. 하나의 world state 안에서 여러 구성요소가 함께 유지되고 서로 영향을 주는 구조를 뜻합니다. 여기서 world state는 현재 무엇이 존재하고, 무엇이 변하고 있으며, 무엇이 다음에 일어날 수 있는지에 대한 내부 표현입니다.

따라서 핵심은 여러 chain of thought를 생성하는 것이 아닙니다. 하나의 internal world state 안에 여러 변화 요소를 함께 두고, 모든 요소를 같은 token sequence를 통해 움직이게 하지 않는 것입니다.

03 / MODALITY는 LENS

세계는 하나의 native format으로 들어오지 않는다.

Text, image, audio, sensor reading은 같은 현실을 서로 다른 방식으로 sampling한 관측입니다.

RGB camera는 특정 전자기파 영역을 잡고, microphone은 공기 압력 변화를 sampling합니다. 한국어와 영어는 같은 사건을 서로 다른 symbol system으로 기록합니다. 다른 생물은 또 다른 spectrum을 봅니다. 어느 modality도 지능의 원래 포맷이라고 볼 특별한 이유는 없습니다.

observation in modality m = lens_m(world state)

여기서 두 번째 설계 원칙이 나옵니다. 학습이나 커뮤니케이션에 쓰인 modality가 내부 계산 형식까지 결정할 필요는 없습니다.

Modality는 세계를 보는 lens다. World model 자체가 그 lens 안에 갇힐 필요는 없다.

04 / ARCHITECTURE

State는 유지하고, event가 바뀐 부분만 갱신한다.

Latent와 stream의 의미를 먼저 정했으니 구조는 단순해집니다. Persistent internal state를 유지하고, 새 event가 들어오면 영향을 받는 부분만 갱신하고, 외부 인터페이스가 필요할 때만 serialize합니다.

Persistent state를 Z = {z1, z2, ..., zK}라고 쓰겠습니다. 각 component는 현재 world model의 서로 다른 부분을 담을 수 있습니다. Event가 들어오면 관련 component만 바뀌면 됩니다.

예를 들어 새로운 소리는 speaker identity, semantic interpretation, dialogue state를 갱신할 수 있습니다. 갑자기 나타난 장애물은 perception, control, planning을 갱신할 수 있습니다. 어느 경우에도 text token 하나가 생성됐다는 이유로 모든 내부 state를 같이 한 칸 전진시킬 필요는 없습니다.

Delayed commitment

같은 구조는 uncertainty를 유지하는 데도 사용할 수 있습니다. 여러 hypothesis가 아직 가능하다면 각각을 evolving state의 서로 다른 component로 남겨 두고, 나중 evidence가 들어왔을 때 중요도를 바꿀 수 있습니다. Continuous vector가 무한한 정보를 담는다는 주장은 필요하지 않습니다. 더 좁은 주장은 discrete token이 특정 quantization과 semantic commitment를 강제하고, 그 결정이 때로는 필요 이상으로 빨리 일어난다는 것입니다.

05 / 세 개의 CLOCK

Token time, compute time, world time은 서로 다르다.

Event가 영향을 받는 state만 갱신할 수 있다면, token counter 하나가 모든 계산의 clock일 필요도 없습니다.

CLOCK 1

Token time

외부 discrete sequence가 symbol을 하나 더 내보낼 때 전진합니다.

CLOCK 2

Compute time

특정 내부 component가 실제로 추가 계산을 수행할 때 전진합니다.

CLOCK 3

World time

관련 있는 외부 event가 발생하면서 전진합니다.

token time != compute time != world time

이 분리가 제안의 핵심입니다. Language decoder는 자기 cadence로 token을 내보내고, vision은 다른 주기로 갱신되며, planning은 새로운 event가 추가 compute를 정당화할 때만 깨어날 수 있습니다.

07 / FALSIFIABLE TESTS

크게 만들기 전에 먼저 깨뜨려 본다.

첫 실험은 architecture 차이가 보이고 compute를 맞출 수 있을 만큼 작아야 합니다.

sequential tokens | parallel tokens | sequential latent | asynchronous multi-stream latent
Asynchronous multi-entity world

여러 entity가 서로 다른 schedule로 변합니다. 독립적으로 변화하는 entity 수가 늘어날 때 tracking accuracy, cross-state interference, FLOPs, memory, latency를 측정합니다.

Delayed evidence

초기 observation은 여러 hypothesis를 지지하고, 뒤의 evidence가 이를 판별합니다. Contradiction 이후 revision cost와 recovery를 측정합니다.

Interruption

모델이 말하거나 행동하는 도중 새로운 정보가 들어옵니다. Reaction latency와 기존 computation을 얼마나 재사용하는지 측정합니다.

Cross-modal action without text

Vision과 audio를 입력하고 non-linguistic action을 요구합니다. 중간 text serialization이 실제 가치를 더하는지, 아니면 latency만 만드는지 비교합니다.

Killer ablationIndependent clock과 interruption을 중심으로 만든 task에서 compute를 맞췄는데도 asynchronous structured state가 더 단순한 sequential 또는 parallel baseline을 이기지 못한다면, 추가 architecture는 정당화되지 않습니다.
