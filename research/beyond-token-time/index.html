PERSISTENT MULTI-STREAM LATENT WORLD STATE

Beyond Token Time.

Language is an interface. Why should it also be the clock, memory format, scheduler, and mandatory substrate of an intelligent system?

Compute when an event requires computation. Update the state that the event affects. Serialize into a modality only when interaction requires serialization.
SectionsToken timeModalities as lensesLatent Event BusPrior workExperimentsPaper
01 / THE PROBLEM

The interface became the computation.

LLMs hold a high-dimensional continuous hidden state, but repeatedly compress the next step through a discrete vocabulary and then reconstruct a new continuous state from the chosen token.

continuous state → discrete token → continuous state

That loop is exactly what we want when the model needs to speak. It is less obvious that the same loop should be compulsory when the model only needs to continue computing internally.

Coconut already gives strong evidence that the answer may be no: it feeds a hidden state back into the model as the next continuous reasoning input instead of decoding every step into language. The more interesting question is what happens when we generalize that idea beyond a single reasoning chain.

The questionWhat if the fundamental unit of intelligent computation were not the next token, but the next relevant event?
Clock 1

Token time

The rhythm of serialized language generation.

Clock 2

Compute time

The moments when an internal process actually needs work.

Clock 3

World time

The external events that change the state an agent models.

token time ≠ compute time ≠ world time
02 / MODALITY

Modalities are lenses, not the world.

A photograph, a sentence, and an audio waveform are different sampled views of the same reality. None of them has a privileged claim to be the native format of intelligence.

An RGB camera sees selected electromagnetic wavelengths. A microphone samples pressure changes. Korean and English encode reality with different symbol systems. Other animals perceive different spectra. A modality is therefore better understood as an observation and communication interface.

observation(m) = lens(m)(world state)

This suggests a design principle: the modality used to train or communicate with a system should not unnecessarily determine the modality in which the system organizes its internal computation.

The world has many lenses. The internal model should not have to live inside one of them.

03 / ARCHITECTURE

A persistent world state, updated by events.

Instead of one chain, maintain multiple latent processes that can represent entities, hypotheses, goals, memories, plans, or sensor-specific state.

Let the persistent state be Z = {z¹, z², …, zᴷ}. An event activates only the streams that need to change. A new sound may update speaker and semantic state; an unexpected obstacle may update perception, control, and planning. There is no requirement that every latent process advance because one language token was emitted.

Important distinctionMultiple streams do not have to mean multiple independent models or multiple textual chains. They can be factors inside one coordinated world state.

Delayed commitment

If several hypotheses remain plausible, the system can keep them as components of the same evolving state and let later evidence modify their relative importance. The claim is not that continuous vectors magically contain infinite information. The useful claim is narrower: a discrete token imposes a particular quantization and semantic commitment, and sometimes that commitment is unnecessarily early.

04 / NOVELTY BOUNDARY

What is actually new here?

Several ingredients already exist. That is important to say explicitly.

WorkAlready demonstratesWhat this proposal changes
CoconutContinuous hidden-state reasoning and latent alternatives.Make latent state persistent across perception, reasoning, and action; not just a replacement for CoT tokens.
Perceiver IOGeneral latent processing across heterogeneous inputs and outputs.Add persistent recurrent state and event-triggered selective updates.
Hybrid Latent Reasoning via RLRL can optimize latent/discrete reasoning policies.Use outcome-driven training to learn state updates and scheduling; RL itself is not the novelty.
Parallel latent TTSSeveral continuous reasoning trajectories can be sampled and ranked.Streams may be entities, goals, sensor processes, or hypotheses inside one state rather than separate solution rollouts.
Multi-Stream LLMsSeveral token streams can read/write in parallel.Internal streams need not be tokens and need not share a single update clock.

The core research claim is therefore deliberately narrow:

General-purpose intelligence may benefit from maintaining a persistent, structured set of latent processes whose updates are triggered asynchronously by relevant events rather than synchronously by token production.
05 / FALSIFIABLE TESTS

Don't scale it first. Try to kill it first.

The first experiment should be small and controlled. Four compute-matched models are enough to find out whether the architectural distinction is real.

sequential tokens · parallel tokens · sequential latent · asynchronous multi-stream latent
Asynchronous multi-entity world

Entities evolve on different schedules. Measure tracking accuracy, interference, FLOPs, memory, and latency as the number of independent processes rises.

Delayed evidence

Early observations support several hypotheses; later evidence resolves them. Measure revision cost and recovery after contradictory evidence.

Interruption

The model starts speaking or acting and receives new information before it finishes. Measure reaction time and how much computation can be reused.

Cross-modal action without text

Give vision and audio input and require a non-linguistic action. Test whether explicit text serialization is actually necessary.

The killer ablationIf asynchronous structured state does not beat simpler sequential or parallel baselines under matched compute on tasks built around independent clocks and interruption, the added architecture is not justified.

01 / 문제 정의

인터페이스가 계산 그 자체가 되어버렸다.

LLM 내부에는 고차원의 연속적인 hidden state가 있지만, 다음 계산으로 넘어갈 때마다 이를 vocabulary의 discrete token으로 압축하고, 선택된 token을 다시 embedding해서 연속 공간을 복원합니다.

continuous state → discrete token → continuous state

사람에게 말을 해야 할 때라면 정확히 필요한 과정입니다. 하지만 모델이 내부적으로 계산을 조금 더 이어가기만 하면 될 때에도 반드시 같은 과정을 거쳐야 하는지는 별개의 문제입니다.

Coconut은 이미 중요한 단서를 보여줍니다. 모든 reasoning step을 언어로 decode하지 않고 hidden state를 다음 continuous reasoning input으로 직접 넣을 수 있습니다. 여기서 한 걸음 더 나아가면, 이 아이디어를 하나의 reasoning chain이 아니라 여러 개의 동시에 움직이는 내부 process로 확장할 수 있을까요?

핵심 질문지능 계산의 기본 단위가 '다음 token'이 아니라 '다음으로 중요한 event'라면 어떻게 될까?

CLOCK 2

02 / MODALITY

Modality는 세계가 아니라 lens다.

사진, 문장, 음성 파형은 같은 현실을 서로 다른 방식으로 sampling한 결과입니다. 어느 하나도 지능의 '원래 포맷'이어야 할 이유는 없습니다.

RGB 카메라는 특정 파장의 전자기파를 보고, 마이크는 공기 압력 변화를 sampling합니다. 한국어와 영어도 현실을 서로 다른 symbol system으로 기록합니다. 다른 생물은 또 다른 스펙트럼을 봅니다. 따라서 modality는 현실 그 자체라기보다 관찰과 커뮤니케이션의 인터페이스라고 보는 편이 자연스럽습니다.

observation(m) = lens(m)(world state)

그러면 하나의 설계 원칙이 나옵니다. 학습이나 커뮤니케이션에 사용된 modality가 모델의 내부 계산 형식까지 강제로 결정해서는 안 된다는 것입니다.

세계에는 여러 lens가 있다. 내부 세계 모델이 그중 하나 안에 갇힐 필요는 없다.

Persistent state를 Z = {z¹, z², …, zᴷ}라고 합시다. 하나의 event가 들어왔을 때 영향을 받는 stream만 갱신합니다. 새로운 소리는 speaker state와 semantic state를 바꿀 수 있고, 갑자기 나타난 장애물은 perception, control, planning을 즉시 깨울 수 있습니다. language token 하나가 생성됐다는 이유만으로 모든 내부 process를 같은 clock으로 한 칸 전진시킬 필요는 없습니다.

중요한 구분multiple stream이라고 해서 여러 모델이나 여러 textual CoT가 필요한 것은 아닙니다. 하나의 coordinated world state 안에서 여러 factor가 동시에 존재할 수 있습니다.

Delayed commitment

여러 hypothesis가 아직 가능하다면 하나를 문장으로 먼저 확정하지 않고 같은 state의 여러 component로 유지할 수 있습니다. continuous vector가 무한한 정보를 담는다는 주장이 아닙니다. 핵심은 discrete token이 특정 quantization과 semantic commitment를 강제하고, 때로는 그 결정 시점이 지나치게 빠르다는 것입니다.

04 / NOVELTY BOUNDARY

그렇다면 무엇이 새롭나?

각각의 재료는 이미 상당 부분 존재합니다. 그래서 이 점을 숨기지 않는 것이 중요합니다.

연구이미 보여준 것이 제안의 차이
Coconutcontinuous hidden-state reasoning과 latent alternative.CoT token 대체를 넘어 perception-reasoning-action 전체에 지속되는 latent state로 확장.
Perceiver IO여러 heterogeneous input/output을 위한 general latent processing.read-process-write를 넘어 persistent recurrence와 event-triggered selective update를 중심으로 둠.
Hybrid Latent Reasoning via RLRL로 latent/discrete reasoning policy를 최적화할 수 있음.RL 자체가 novelty가 아니라 latent state의 update와 scheduling policy를 학습하는 수단.
Parallel latent TTS여러 continuous reasoning trajectory를 sampling하고 선택.stream이 독립적인 answer rollout일 필요 없이 entity, goal, sensor process, hypothesis가 될 수 있음.
Multi-Stream LLMs여러 token stream의 동시 read/write.내부 stream이 token일 필요가 없고 같은 clock으로 update될 필요도 없음.

따라서 논문의 claim은 의도적으로 좁혀야 합니다.

범용 지능은 token 생성에 동기화된 하나의 상태보다, 관련 event에 의해 비동기적으로 갱신되는 persistent하고 structured한 latent process 집합에서 이득을 얻을 수 있다.
05 / FALSIFIABLE TESTS

먼저 크게 만들지 말고, 먼저 틀렸는지 확인하자.

첫 실험은 작고 통제되어야 합니다. 네 종류의 compute-matched model만 비교해도 architecture 차이가 실제인지 상당 부분 알 수 있습니다.

sequential tokens · parallel tokens · sequential latent · asynchronous multi-stream latent
Asynchronous multi-entity world

여러 entity가 서로 다른 주기로 변합니다. entity 수가 늘어날 때 tracking accuracy, interference, FLOPs, memory, latency를 측정합니다.

Delayed evidence

초기에는 여러 hypothesis가 가능하고 뒤늦게 정답을 가르는 evidence가 들어옵니다. contradiction 이후 recovery와 revision cost를 봅니다.

Interruption

모델이 말하거나 행동하는 중간에 새로운 정보가 들어옵니다. reaction latency와 기존 computation의 재사용 정도를 측정합니다.

Cross-modal action without text

vision과 audio를 입력하고 비언어적 action을 요구합니다. 중간 text serialization이 실제로 필요한지 검증합니다.

Killer ablationindependent clock과 interruption을 중심으로 만든 task에서, compute를 맞췄는데도 asynchronous structured state가 더 단순한 baseline을 이기지 못한다면 이 architecture의 복잡성은 정당화되지 않습니다.
