PERSISTENT MULTI-STREAM LATENT WORLD STATE

Beyond Token Time.

Language is an interface. Why should it also serve as the clock, memory format, scheduler, and mandatory substrate of an intelligent system?

Compute when an event requires computation. Update the state that the event affects. Serialize into a modality only when interaction requires serialization.

01 / THE PROBLEM

The interface became the computation.

Current LLMs expose a curious bottleneck: they maintain a high-dimensional continuous hidden state, but repeatedly compress the next step through a discrete vocabulary and then reconstruct a new continuous state from the chosen token.

continuous state → discrete token → continuous state

That loop is exactly what is needed when the model has to speak. Less obvious is why the same loop should be compulsory when the model only needs to continue computing internally.

Coconut provides an important proof of possibility: a model can feed a hidden state back as the next continuous reasoning input instead of decoding every intermediate step into language. The important point is not simply “continuous chain of thought,” but that token emission can become optional. That leaves a broader question: what if the same freedom applied not only to one reasoning chain, but to several internal processes that coexist over time?

The questionWhat if the fundamental unit of intelligent computation were not the next token, but the next relevant event?
Clock 1

Token time

The rhythm of serialized language generation.

Clock 2

Compute time

The moments when an internal process actually needs work.

Clock 3

World time

The external events that change the state an agent models.

token time ≠ compute time ≠ world time
02 / MODALITY

Modalities are lenses, not the world.

A useful way to think about modality is simple: a photograph, a sentence, and an audio waveform are different sampled views of the same reality. None has a privileged claim to be the native format of intelligence.

An RGB camera sees selected electromagnetic wavelengths. A microphone samples pressure changes. Korean and English encode reality with different symbol systems. Other animals perceive different spectra. A modality is therefore better understood as an observation and communication interface, not as reality itself.

observation(m) = lens(m)(world state)

This leads to a design principle: the modality used to train or communicate with a system should not unnecessarily determine the format in which the system organizes its internal computation.

The world has many lenses. The internal model should not have to live inside one of them.

03 / ARCHITECTURE

A persistent world state, updated by events.

The proposed shift is to replace the image of a single thought chain with a persistent set of latent processes that can represent entities, hypotheses, goals, memories, plans, dialogue state, or sensor-specific state.

Let the persistent state be Z = {z¹, z², …, zᴷ}. An event should activate only the streams that need to change. A new sound may update speaker and semantic state; an unexpected obstacle may update perception, control, and planning. There is no fundamental reason every latent process must advance merely because one language token was emitted.

Multiple streamsThis does not mean several independent models or several textual chains. It means several coordinated factors inside one evolving world state.

Delayed commitment

If several hypotheses remain plausible, the system should be able to keep them as components of the same evolving state and let later evidence change their relative importance. This does not require claiming that a continuous vector magically contains infinite information. The narrower claim is that a discrete token imposes a particular quantization and semantic commitment, and sometimes that commitment is unnecessarily early.

04 / PRIOR WORK

Lessons from prior work — and where the proposal pushes further.

This idea does not start from a blank page. Several important pieces already exist. The useful question is what each line of work establishes, and which assumption remains worth relaxing.

WorkWhat it establishesNext question explored here
CoconutHidden states can continue reasoning without language, and latent states can preserve alternatives.Extend that freedom across perception, reasoning, and action rather than use it only as a replacement for CoT tokens.
Perceiver IOA shared latent space can mediate heterogeneous inputs and outputs.Make the latent state persist across events, recur over time, and update selectively rather than mainly serve a read-process-write pass.
Hybrid Latent Reasoning via RLRL can optimize policies that move between latent and discrete reasoning.Use RL as a way to learn when and what to update in persistent state; RL itself is not the novelty.
Parallel latent TTSSeveral continuous reasoning trajectories can be explored and compared.Let multiple latent components coexist inside one world state — as entities, goals, sensor processes, or hypotheses — rather than only as independent answer rollouts.
Multi-Stream LLMsSeveral token streams can read and write concurrently.Ask why internal streams must be tokens at all, or why they should share one update clock.

The resulting claim is deliberately narrow:

General-purpose intelligence may benefit from maintaining a persistent, structured set of latent processes whose updates are triggered asynchronously by relevant events rather than synchronously by token production.
05 / FALSIFIABLE TESTS

Don't scale it first. Try to break it first.

Before building a large system, a small controlled experiment should test whether this architectural distinction is real. Four compute-matched models are already informative.

sequential tokens · parallel tokens · sequential latent · asynchronous multi-stream latent
Asynchronous multi-entity world

Entities evolve on different schedules. Measure tracking accuracy, interference, FLOPs, memory, and latency as the number of independent processes rises.

Delayed evidence

Early observations support several hypotheses; later evidence resolves them. Measure revision cost and recovery after contradictory evidence.

Interruption

The model starts speaking or acting and receives new information before it finishes. Measure reaction time and how much prior computation can be reused.

Cross-modal action without text

Give vision and audio input and require a non-linguistic action. The test is whether explicit text serialization is actually necessary.

The killer ablationIf asynchronous structured state does not beat simpler sequential or parallel baselines under matched compute on tasks built around independent clocks and interruption, the added architecture is not justified.

01 / 문제 정의

인터페이스가 계산 그 자체가 되어버렸다.

현재 LLM에서 가장 흥미로운 병목은 이겁니다. 내부에는 고차원의 연속적인 hidden state가 있는데, 계산을 이어갈 때마다 이를 vocabulary의 discrete token으로 압축하고, 선택된 token을 다시 embedding해서 연속 공간을 복원합니다.

continuous state → discrete token → continuous state

사람에게 말을 해야 할 때라면 정확히 필요한 과정입니다. 하지만 모델이 내부 계산을 조금 더 이어가기만 하면 될 때에도 반드시 같은 과정을 거쳐야 하는지는 별개의 문제입니다.

Coconut이 보여주는 중요한 가능성은 모든 reasoning step을 언어로 decode하지 않고 hidden state를 다음 continuous reasoning input으로 직접 넣을 수 있다는 점입니다. 핵심은 단순히 “continuous chain of thought”가 아니라 token을 내보내는 행위가 선택적일 수 있다는 데 있습니다. 여기서 질문을 하나 더 밀어볼 수 있습니다. 이 자유를 하나의 reasoning chain뿐 아니라, 시간에 따라 함께 존재하는 여러 내부 process까지 확장하면 어떻게 될까요?

핵심 질문지능 계산의 기본 단위가 '다음 token'이 아니라 '다음으로 중요한 event'라면 어떻게 될까?
CLOCK 1

Token time

언어를 직렬화해서 생성하는 시간축.

CLOCK 2

Compute time

특정 내부 process가 실제로 계산을 필요로 하는 시점.

CLOCK 3

World time

에이전트가 모델링하는 외부 세계가 변하는 event.

token time ≠ compute time ≠ world time
02 / MODALITY

Modality는 세계가 아니라 lens다.

Modality를 이렇게 볼 수 있습니다. 사진, 문장, 음성 파형은 같은 현실을 서로 다른 방식으로 sampling한 결과입니다. 어느 하나도 지능의 '원래 포맷'이어야 할 이유는 없습니다.

RGB 카메라는 특정 파장의 전자기파를 보고, 마이크는 공기 압력 변화를 sampling합니다. 한국어와 영어도 현실을 서로 다른 symbol system으로 기록합니다. 다른 생물은 또 다른 스펙트럼을 봅니다. 따라서 modality는 현실 그 자체라기보다 관찰과 커뮤니케이션을 위한 인터페이스로 보는 편이 더 자연스럽습니다.

observation(m) = lens(m)(world state)

여기서 하나의 설계 원칙이 나옵니다. 학습이나 커뮤니케이션에 사용된 modality가 모델의 내부 계산 형식까지 강제로 결정할 필요는 없습니다.

세계에는 여러 lens가 있다. 내부 세계 모델이 그중 하나 안에 갇힐 필요는 없다.

Persistent state를 Z = {z¹, z², …, zᴷ}라고 두겠습니다. 하나의 event가 들어왔을 때 영향을 받는 stream만 갱신합니다. 새로운 소리는 speaker state와 semantic state를 바꿀 수 있고, 갑자기 나타난 장애물은 perception, control, planning을 즉시 깨울 수 있습니다. language token 하나가 생성됐다는 이유만으로 모든 내부 process가 같은 clock으로 한 칸 전진해야 할 근본적인 이유는 없습니다.

Multiple stream의 의미여러 개의 독립 모델이나 여러 textual CoT를 뜻하는 게 아닙니다. 하나의 coordinated world state 안에 여러 factor가 함께 존재하는 구조를 뜻합니다.

Delayed commitment

여러 hypothesis가 아직 가능하다면 하나를 문장으로 먼저 확정하기보다, 같은 state의 여러 component로 유지한 채 뒤의 evidence가 상대적인 중요도를 바꾸게 할 수 있습니다. continuous vector가 무한한 정보를 담는다는 주장은 아닙니다. 더 좁은 주장은 discrete token이 특정 quantization과 semantic commitment를 강제하고, 때로는 그 결정 시점이 지나치게 빠를 수 있다는 것입니다.

04 / 선행 연구

선행연구에서 배운 것과 더 밀어볼 지점.

이 아이디어는 빈 종이에서 시작하지 않습니다. 중요한 조각들은 이미 여러 연구에 있습니다. 핵심은 각각의 연구가 어떤 가능성을 열었고, 그 다음에 어떤 제약을 더 풀 수 있느냐입니다.

연구이미 보여준 것여기서 더 밀어볼 지점
Coconut언어를 거치지 않고 hidden state로 reasoning을 이어갈 수 있고, latent state가 여러 alternative를 보존할 수 있다.이 자유를 CoT token 대체에만 쓰지 않고 perception-reasoning-action 전체에 지속되는 state로 확장한다.
Perceiver IO하나의 latent space가 heterogeneous input과 output 사이의 공통 계산 공간이 될 수 있다.latent state가 event 사이에서도 지속되고, 시간에 따라 recurrent하게 유지되며, 필요한 부분만 selective update되는 구조로 확장한다.
Hybrid Latent Reasoning via RLRL로 latent/discrete reasoning policy를 최적화할 수 있다.RL은 persistent state의 update와 scheduling을 학습하는 수단으로 본다. RL 자체가 novelty는 아니다.
Parallel latent TTS여러 continuous reasoning trajectory를 동시에 탐색하고 비교할 수 있다.여러 stream을 독립 answer rollout이 아니라 하나의 world state 안에서 공존하는 entity, goal, sensor process, hypothesis로 둔다.
Multi-Stream LLMs여러 token stream을 동시에 read/write할 수 있다.내부 stream이 왜 반드시 token이어야 하는지, 또 왜 모두 같은 update clock을 가져야 하는지 묻는다.

따라서 실제 claim의 범위는 의도적으로 좁습니다.

범용 지능은 token 생성에 동기화된 하나의 상태보다, 관련 event에 의해 비동기적으로 갱신되는 persistent하고 structured한 latent process 집합에서 이득을 얻을 수 있다.
05 / FALSIFIABLE TESTS

먼저 크게 만들기보다, 먼저 틀렸는지 확인한다.

큰 시스템을 만들기 전에 작은 controlled experiment로 이 architecture 차이가 실제인지부터 확인합니다. 네 종류의 compute-matched model만 비교해도 상당히 많은 것을 알 수 있습니다.

sequential tokens · parallel tokens · sequential latent · asynchronous multi-stream latent
Asynchronous multi-entity world

여러 entity가 서로 다른 주기로 변하게 하고, entity 수가 늘어날 때 tracking accuracy, interference, FLOPs, memory, latency를 측정합니다.

Delayed evidence

초기에는 여러 hypothesis가 가능하고 뒤늦게 정답을 가르는 evidence가 들어오게 합니다. contradiction 이후 recovery와 revision cost를 봅니다.

Interruption

모델이 말하거나 행동하는 중간에 새로운 정보가 들어오게 합니다. reaction latency와 기존 computation을 얼마나 재사용할 수 있는지 측정합니다.

Cross-modal action without text

vision과 audio를 입력하고 비언어적 action을 요구합니다. 중간 text serialization이 실제로 필요한지 직접 검증합니다.

Killer ablationindependent clock과 interruption을 중심으로 만든 task에서 compute를 맞췄는데도 asynchronous structured state가 더 단순한 baseline을 이기지 못한다면, 이 architecture의 추가 복잡성은 정당화되지 않습니다.
